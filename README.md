# IPL Analysis Dashboard (2008–2025)

## Project Overview

This project is an interactive IPL (Indian Premier League) Analysis Dashboard built using Power BI. The dashboard provides season-wise insights from IPL 2008 to 2025 including team performance, Orange Cap winners, Purple Cap winners, match statistics, and points table analysis.

The project focuses on sports analytics and visual storytelling using interactive Power BI dashboards.

# Features

- Dynamic season-wise filtering (2008–2025)
- IPL Winner and Runner-Up analysis
- Orange Cap holder analysis
- Purple Cap holder analysis
- Team points table
- Total sixes and fours statistics
- Match and venue statistics
- Interactive Power BI dashboard
- Team logos and player visuals
